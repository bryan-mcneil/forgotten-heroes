# studio — Corgi Space Cadet (brand, intro, landing page)

## What lives here

- `brand.md` and `logo/`: the studio brand kit — corgi frames, logo type, palette (Step 57).
- `site/`: the static landing page for `corgi.bryanmcneil.pro`, deployed to Hostinger with Git deploy
  (Step 59). The intro animation (Step 58) and the favicons, Open Graph image and PWA manifest
  (Step 60) are specified in `knowledge/game_design_document.md` §11.

## What must NOT live here

- Game code or game assets. The studio page links to the game; it does not embed it.
- Anything deployed to AWS. This site goes to Hostinger, so none of it belongs in `infra/`.
